Place replacement SVG, PNG, JPG, JPEG, WebP, GIF, AVIF, BMP or ICO images here.
Set their paths in ../../images.json, for example ./assets/custom/ct.jpg.
Icons and weapons accept either a direct path string or a { "src": "...", "tint": false } object.
Use tint false for full-color and JPG images. Tint true uses transparency as a colored mask.
Refresh the OBS browser source after making changes.
Back up this folder and images.json before importing an addon update.
